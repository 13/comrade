# comrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `comrade`, a zero-config Linux TUI serial monitor. It auto-detects USB microcontrollers, streams their output into tabs, survives reset/replug, and steps aside automatically during uploads.

**Architecture:** There is one binary crate and no async runtime. Worker threads each send an `Event` into one crossbeam channel: udev monitor, inotify opener-watch, one serial worker per open port, and terminal input. The app thread owns a pure `Core` state machine (`handle(event, now) -> Vec<Command>`) and executes the returned `Command`s against the I/O layer. It renders with ratatui only when state is dirty, at most 60 fps. All board/pause/line logic is pure and unit-tested. The I/O modules are thin and get pty-based tests.

**Tech Stack:** Rust 1.99, edition 2024. Crates: `ratatui`, `crossterm`, `udev`, `inotify`, `serialport` (`default-features = false`), `nix` (poll, eventfd, signal), `crossbeam-channel`, `ansi-to-tui`, `unicode-width`, `chrono`, `serde`, `toml`, `directories`, `anyhow`, `thiserror`, `clap` (derive). Dev: `tempfile`, `nix` pty (`openpty`). Use the current published versions at build time.

**Spec:** `docs/superpowers/specs/2026-11-14-comrade-design.md`. Read it before any task. Section numbers below (§x.y) refer to it.

## Global Constraints

- Linux only. No root, no config file, no wrapper command required. CLI flags are overrides only: `--baud <u32>`, `--port <path>` (repeatable).
- Never set `TIOCEXCL` and never `flock` a port. `serialport` sets `TIOCEXCL` on open, so call `set_exclusive(false)` immediately after open.
- Default baud: `115200`. Baud picker list: `300 1200 2400 4800 9600 19200 38400 57600 74880 115200 230400 460800 921600 1000000 1500000 2000000`, plus custom entry.
- Scrollback: `100_000` lines per tab (ring buffer, oldest dropped).
- Render: dirty-only, max 60 fps (≥ 16 ms between frames).
- Upload pause: reopen the same node immediately on foreign release (target ≤ 10 ms). Re-enumeration quiet period is `500 ms`. Global auto-connect block safety net is `60 s`.
- Connect latency target: ≤ 20 ms after udev add event.
- State file: `$XDG_STATE_HOME/comrade/boards.toml` (default `~/.local/state/comrade/boards.toml`). A missing or corrupt file is ignored and rewritten, never fatal.
- Save file name: `./comrade-<board-name>-<YYYYMMDD-HHMMSS>.log`.
- Separator lines (exact text, `HH:MM:SS` local time): `──── upload · HH:MM:SS ────`, `──── reconnected · HH:MM:SS ────`, `──── reset · HH:MM:SS ────`.
- Tab glyphs: `●` connected, `⏸` paused, `○` unplugged/waiting, `!` error.
- Permission message (exact, `<dev>` and `<group>` substituted, group name from the node's gid): `no permission for <dev> — add yourself to group '<group>' and re-login`.
- No `unwrap`/`expect` on I/O paths. A panic hook restores the terminal. A dead worker thread is treated as `PortGone`.
- Key bindings exactly as spec §6.8.

## Review Focus

1. **A line that never ends** (wrong baud garbage, binary stream). The 100k-line cap must not be defeated by one unbounded line. Force a break at `16_384` bytes. Test: Task 2 `long_line_is_split`.
2. **Firmware emitting non-SGR escapes** (`ESC[2J`, cursor moves, OSC). These must never reach the real terminal or corrupt layout. Strip all except SGR. Test: Task 2 `strips_non_sgr_escapes`.
3. **Two identical CH340 boards with no serial number.** They must stay separate tabs keyed by USB path, and replug into the same physical USB port must reattach to the right tab. Test: Task 1 `serialless_boards_keyed_by_path`.
4. **Unplug while sending, or a stale reader event after a reconnect.** A write to a gone port must not crash. `PortData`/`PortGone` with an old `ConnId` must be ignored. Test: Task 4 `stale_conn_events_ignored`, Task 6 `write_after_unplug_reports_gone`.
5. **Tiny or zero-size terminal** (e.g. 10×3, or 0 rows mid-resize). Render must not panic. Test: Task 9 `render_tiny_terminal_no_panic`.

### Task 2: Line assembler

**Files:**
- Create: `src/lines.rs`
- Test: unit tests in `src/lines.rs`

**Interfaces:**
- Produces:
  - `#[derive(Clone, Debug, PartialEq)] pub enum LineKind { Data, Separator, Info, Error }`
  - `#[derive(Clone, Debug)] pub struct Line { pub at: chrono::DateTime<chrono::Local>, pub kind: LineKind, pub text: String }`. For `Data`, `text` keeps SGR sequences only.
  - `pub struct LineAssembler` with `pub fn new() -> Self`
  - `pub fn push(&mut self, bytes: &[u8], at: DateTime<Local>) -> Pushed`
  - `pub struct Pushed { pub complete: Vec<Line>, pub partial_changed: bool, pub rom_banner: bool }`
  - `pub fn partial(&self) -> Option<&Line>`: the current unterminated line, displayed live.
  - `pub fn flush(&mut self) -> Option<Line>`: used on disconnect.
  - `pub const MAX_LINE_BYTES: usize = 16_384;`

Rules:
- `\n` ends a line. `\r\n` is one break. A bare `\r` ends a line. A `\r` at the end of a chunk followed by `\n` at the start of the next chunk is still one break.
- A line's `at` is the time of its first byte.
- Invalid UTF-8 is decoded lossily. A multi-byte char split across chunks must decode correctly.
- ESC sequences: keep complete SGR (`ESC [ … m`). Drop all other CSI, OSC (`ESC ]` … BEL/ST) and bare ESC+char. An escape sequence split across chunks must be handled.
- Other C0 controls except `\t` are shown as Unicode control pictures (`\0` → `␀`, U+2400 + byte).
- Force a break at `MAX_LINE_BYTES`.
- `rom_banner = true` if a completed line starts with `ESP-ROM:` or `rst:0x`, after stripping SGR.

Behavior (spec §6.2, §6.3, §6.6, §6.10):
- `DeviceAdded`:
  - `Class::Other`: store it in other-ports and stop.
  - `Class::Bootloader`: store it in other-ports and stop.
  - `Class::Auto`: find or create the tab by `board_key`, set `devnode`. If `pause.allows_auto_connect(now)`, then bump `conn` (global counter), set `Connecting`, and emit `Open`. Also emit `Watch(all present Auto/Bootloader devnodes)` whenever that set changes.
- Focus rule for a new tab: focus it only if the focused tab is not `Connected`. Otherwise set `highlight = true`. Focusing a tab clears its `highlight`.
- `PortOpened` (matching conn) → `Connected`. On a reconnect (the tab had connected before), push the separator `──── reconnected · HH:MM:SS ────`.
- `PortOpenFailed` → `Error`. For `PermissionDenied`, use the exact permission message from Global Constraints.
- `PortData` (matching conn): `asm.push`, append complete lines to `scroll`, add to `rx_bytes`. If `rom_banner` and the tab has seen data before in this connection, push `──── reset · HH:MM:SS ────` before the banner line.
- `PortGone` (matching conn) or `DeviceRemoved` for the tab's devnode: flush the partial line, set `Waiting`, `devnode = None`, emit `Close`.
- **Events with a stale `conn` are ignored.**
- `Send(s)` on a Connected tab → `Write` with the line ending appended. On other tabs it is a no-op plus an `Info` line `not connected`.
- `SetBaud` → `SetBaud` (if connected) + `Persist`.
- `CycleLineEnding` → `Persist`.
- `Reset` → `ResetPulse` + separator `reset`.
- `TogglePause` → `Close` + `Paused(Manual)`, or `Open` with a new conn.
- `CloseTab`: on an unplugged tab, remove it. On a connected tab, `Close` and hide it until the next `DeviceAdded`.
- `ConnectOther(path)` opens a non-auto port as a tab with family `Unknown`.
- Ports from `--port` (`manual_ports`) are opened at startup as `Unknown` tabs, regardless of class.

### Task 5: Upload pause + persistence

**Files:**

**Interfaces:**
- Produces (`pause.rs`):
  - `pub struct PauseTracker`
  - `pub fn foreign_open(&mut self, devnode: &Path, holder: Holder, now: Instant)`
  - `pub fn foreign_released(&mut self, devnode: &Path, now: Instant)`
  - `pub fn allows_auto_connect(&self, now: Instant) -> bool`
  - `pub fn deadline(&self) -> Option<Instant>`
  - `pub const QUIET: Duration = 500ms; pub const SAFETY: Duration = 60s;`
- Produces (`store.rs`):
  - `#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)] pub struct BoardPrefs { pub baud: u32, pub line_ending: LineEnding }`
  - `pub fn state_path() -> Option<PathBuf>`
  - `pub fn load(path: &Path) -> HashMap<BoardKey, BoardPrefs>`: never errors. Corrupt → empty + `log` to stderr only before the TUI starts.
  - `pub fn save(path: &Path, map: &HashMap<BoardKey, BoardPrefs>) -> io::Result<()>`: atomic write via temp file + rename.

`allows_auto_connect(now)` is true when either condition holds:
- no holders remain, and the last release happened at least `QUIET` ago;
- the oldest current holder started at least `SAFETY` ago.

Core integration (spec §6.4):
- `ForeignOpen{devnode}` when a tab is Connected/Connecting on that devnode → `Close`, `Paused(Upload(holder))`, push separator `──── upload · HH:MM:SS ────`. Always record the holder in the tracker.
- `ForeignReleased{devnode}`: update the tracker. If a tab is `Paused(Upload)` on that devnode and the node is still present → `Open` immediately with a new conn (**no quiet period**).
- `DeviceAdded` while auto-connect is blocked: create or update the tab as `Waiting` and do not emit `Open`. Bootloaders are never opened (Task 4).
- `on_timer`: once `allows_auto_connect` becomes true, emit `Open` for every present Auto device whose tab is `Waiting` or new, never for `Paused(Manual)`. Then `next_deadline` = `min(tracker.deadline())`.
- A tab `Paused(Upload)` whose device was removed becomes `Waiting` when its holder releases (the upload failed or the board was unplugged).
- `Persist` commands are executed by the app via `store::save`.

### Task 6: Serial I/O worker

**Files:**
- Create: `src/io/mod.rs`, `src/io/serial.rs`
- Test: `tests/pty_serial.rs`

**Interfaces:**
- Consumes: `Event`, `BoardKey`, `ConnId`, `LinePolicy`, `Family`, `OpenError`.
- Produces:
  - `pub struct PortHandle` (held by the app per key) with `pub fn write(&self, bytes: Vec<u8>)`, `pub fn set_baud(&self, baud: u32)`, `pub fn reset_pulse(&self, family: Family)`, and `pub fn close(self)`. `close` signals the worker and returns without joining. The worker closes the fd within one poll wakeup.
  - `pub fn spawn_port(key: BoardKey, conn: ConnId, devnode: PathBuf, baud: u32, policy: LinePolicy, tx: Sender<Event>) -> PortHandle`

Worker contract:
- Opens with `serialport::new(dev, baud).dtr_on_open(policy.dtr)` (if the crate lacks the method, set the lines right after open) then `.open_native()`.
- Immediately: `set_exclusive(false)`, `write_data_terminal_ready(policy.dtr)`, `write_request_to_send(policy.rts)`, no flow control, 8N1.
- Then sends `PortOpened`.
- On `EACCES` it sends `PortOpenFailed{PermissionDenied{group}}`, with the group name from the node's gid via `nix::unistd::Group::from_gid`.
- Loop: `poll([port_fd POLLIN, eventfd POLLIN], -1)`.
  - Readable → read into a reused 8 KiB buffer and send `PortData` (one event per read).
  - `POLLHUP`/`POLLERR`/`EIO`/`ENXIO`/`ENODEV`/0-byte read → `PortGone` and exit.
  - Command queue (crossbeam) is drained on each eventfd wake: Write (on error → `PortGone`), SetBaud, ResetPulse, Close (drop the port → exit without an event).
- `ResetPulse`:
  - `UartBridge`/`EspUsbJtag`: `dtr=false; rts=true; sleep 100ms; rts=false`. This puts the chip in run mode, IO0 high.
  - `NativeCdc`/`Unknown`: `dtr=false; sleep 50ms; dtr=true`.
  - Afterwards the lines return to the policy state.
- The worker body is wrapped in `catch_unwind`. A panic → `PortGone{reason:"worker panicked"}`.

### Task 7: Opener watch (foreign-open detection)

**Files:**
- Create: `src/io/opener_watch.rs`
- Test: `tests/pty_opener.rs`

**Interfaces:**
- Produces:
  - `pub struct OpenerWatch` with `pub fn spawn(tx: Sender<Event>) -> io::Result<Self>`, `pub fn set_watched(&self, nodes: Vec<PathBuf>)` (called on `Command::Watch`), `pub fn note_own_open(&self, node: &Path)`, `pub fn note_own_close(&self, node: &Path)`
  - `pub fn foreign_holders(node: &Path, own_pid: u32) -> Vec<Holder>`: scans `/proc/[0-9]*/fd/*`, follows `readlink`, compares against the canonical node path, reads the name from `/proc/<pid>/comm` (trimmed). Unreadable dirs are skipped.
- The app calls `note_own_open` before spawning a port and `note_own_close` on `Close`. The counters are shared (`Arc<Mutex<HashMap<PathBuf,(u32,u32)>>>`).

Algorithm per node (because inotify can merge identical unread events, a `/proc` scan is the authority whenever it can see the holder):
```
state: Option<Holder> per node (None = free)
on IN_OPEN:
    named = foreign_holders(node)
    own   = take_own_open(node)            // decrements counter if >0
    if !named.is_empty()        -> set state = named[0]; emit ForeignOpen if it was None
    else if !own                -> set state = Unknown;  emit ForeignOpen if it was None
on IN_CLOSE_WRITE | IN_CLOSE_NOWRITE:
    own   = take_own_close(node)
    named = foreign_holders(node)
    if state.is_some() && named.is_empty() && (!own || state != Unknown)
                                -> state = None; emit ForeignReleased
on IN_IGNORED / IN_DELETE_SELF (node removed): drop the watch; if state was Some -> emit ForeignReleased
```
`set_watched` adds and removes inotify watches via the `Watches` handle, so the reading thread is never blocked.

**Files:**
- Create: `src/app.rs`, `README.md`

**Interfaces:**
- Consumes: everything above.

App loop:
- Spawn the threads: udev, opener watch, and a crossterm input thread (`crossterm::event::read` → `Event::Input`).
- `select` on the event channel with `recv_deadline(min(core.next_deadline(), next_frame, next_rate_tick))`.
- After draining all ready events (non-blocking `try_recv` loop, so floods coalesce), run `core.on_timer(now)` and execute the commands:
  - `Open` → `note_own_open` + `spawn_port`, store the handle by key
  - `Close` → `note_own_close` + `handle.close()`
  - `Write`/`SetBaud`/`ResetPulse` → the handle
  - `Watch` → `opener.set_watched`
  - `Persist` → update the map + `store::save`. Errors become a status message, never fatal.
- Render if dirty and ≥ 16 ms since the last frame.
- `UiOutcome::Save` writes the focused tab's scrollback as plain text (SGR stripped, timestamps included if enabled) to `./comrade-<name>-<YYYYMMDD-HHMMSS>.log` and shows the path in the status line.

`main.rs`:
- Parse args.
- Panic hook: `disable_raw_mode`, `LeaveAlternateScreen`, `DisableMouseCapture`, show cursor, then the default hook.
- `SIGTERM`/`SIGHUP` handling via a `signal-hook`-style flag. Use `nix` sigaction plus an `AtomicBool` checked on each loop wake. The input thread provides wakeups, and so does a 250 ms max `recv` timeout.
- Enter the alternate screen, enable raw mode and mouse capture, `run`, restore.
